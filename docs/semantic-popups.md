# 语义弹窗规范

弹窗不是字幕的复制品，而是把一句话压缩成观众需要记住的一个结论。先找口播中的重音词和动作，再确定组件与时间范围。

## 语义到组件

| 口播作用 | 推荐组件 | 示例文案 |
| --- | --- | --- |
| 开场承诺 | 核心观点卡 | 最简单 · 最详细 |
| 方法/态度 | 轻量标签卡 | 纯实操 |
| 动作步骤 | 步骤卡 | 手把手安装 |
| 工具关系 | 流程/桥接卡 | DeepSeek → Codex |
| 结果确认 | 结果卡 | Codex 已安装 |
| 下一步/行动 | CTA 卡 | 更多教程 |

每个字段尽量不超过 15 个汉字；一组画面最多一个主结果卡和两三个辅助元素。

## 时间锚点

每张卡记录 `start`、`trigger`、`end` 和 `exitStart`：

- `start`：卡片开始进入；
- `trigger`：重音词真正开始的时间，优先使用词级时间轴；
- `end`：卡片完全退出的时间；
- `exitStart`：淡出开始，通常在结论说完前约 0.2–0.3 秒。

入场约 0.18–0.28 秒，透明度从 0 到 1、位移约 20px、缩放 96%→100%。退出约 0.20–0.28 秒。不要按固定秒数贴卡，也不要让卡片跨越下一个语义组。

## 版式与安全区

- 深色半透明面板，圆角 16–20px，细边框和轻阴影；
- 蓝色表示输入/动作，紫色表示关系/步骤，绿色表示结果，珊瑚色表示行动提醒；
- 卡片放在左上或右上安全区，避开眼睛、嘴部、手势和底部字幕区；
- 人物居中时，信息层收在眉眼以上或侧边空白处；
- 文档/聊天弹窗只展示关键证据，不塞入整页小字。

## 语义检查

渲染前逐组回答：

1. 观众只看卡片，能否知道当前论点？
2. 卡片触发是否落在对应重音词，而不是整句结束后？
3. 输入、关系、结果是否按顺序出现？
4. 结论后是否留有干净停顿？
5. 卡片是否遮挡人物或既有字幕？
