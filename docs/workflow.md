# 视频制作流程

这套流程的核心是先锁定“声音说到哪里”，再决定画面何时出现。每个阶段都有可检查的产物；上一阶段未通过时，不进入下一阶段。

## A. 素材与风格校准

输入原始最高画质视频、可选脚本、已有字幕、配乐、录屏和参考图。记录画幅、帧率、时长和音轨，确认人物、眼睛、嘴部、手势及底部约 25% 为保护区。参考图只提取构图、颜色、字体和节奏，不复制品牌元素。

产物：风格拆解表、画面安全区、卡片规则、禁止项和待确认项。

## B. 转写、字幕轴与语义组

先做逐句时间轴，再做词级/字级时间轴。校正专有名词、错别字和中英文名称，保留原声作为最终同步基准。按完整论证单元分组，不按标点机械切卡；字幕记录“说了什么”，弹窗只保留观众需要记住的结论。

产物：校正 SRT、词级 JSON、语义组表、音频与文稿差异记录。

## C. 静态关键帧门禁

为开场、每个主要逻辑组、信息量最大画面、录屏画中画（如有）和结尾生成静态帧。逐帧检查：

- 输入 → 关系 → 结果的顺序是否清楚；
- 卡片文字是否完整收在面板内；
- 人脸、眼睛、嘴部、手势和底部字幕是否无遮挡；
- 旧逻辑组是否在新组开始前退出。

关键帧未通过时停止，不渲染动态预览。

## D. 动态审核版

关键帧通过后输出 15–20 秒审核预览，保留原声并重新编码为 AAC。卡片入场使用约 0.18–0.28 秒的透明度、20px 位移和 96%→100% 缩放；关键词在真实重音词开始后约 0–220ms 触发。每个逻辑组结论说完后整体淡出，并留出约 1.5–2 秒干净画面。

审核重点：字幕/原声同步、关键词触发、卡片累积与退出、录屏画面是否保持原样、音轨是否可播放。

## E. 定点修改与最终渲染

修改请求写成“时间点 + 对象 + 当前问题 + 目标状态”，一轮只改相关对象。先抽取受影响位置前后 2–3 秒的帧或短片段，确认后再从原始素材重新渲染正式成片。最后用媒体探针对照分辨率、时长、帧率、H.264 编码和 AAC 音轨。

## F. 风格资产沉淀

确认成片后更新可跨视频复用的 `style-guide.md`、启动提示词、参考图索引和 lessons learned。只记录通用规则、有效修改和失败版式；不要把本期标题、台词、绝对路径或临时素材写进通用 Skill。
