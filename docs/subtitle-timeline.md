# 字幕时间轴

字幕层与语义弹窗分开管理。创作者可以自己在剪映、Premiere 或其他工具中添加字幕；Skill 只负责提供可对齐的时间轴和校验方法。

## 推荐产物

### 逐句 SRT

```srt
1
00:00:00,230 --> 00:00:03,870
示例句子
```

按完整语义句分组，避免为了追求短行而切断一句话。时间码以源视频音频为准，毫秒级保存。

### 词级 JSON

每个词至少包含：

```json
{
  "text": "安装",
  "startMs": 8130,
  "endMs": 8550,
  "timestampMs": 8130,
  "confidence": 0.94
}
```

`timestampMs` 用于动效触发；不能用整句起点代替关键词的真实时间。若识别结果与口播不一致，保留修正记录，不静默覆盖原始数据。

## 同步验收

- 随机抽查 5–10 个关键词，听感与卡片触发误差控制在约 80–220ms 内；
- 说话人停顿、重复和改口不应导致卡片提前出现；
- 录屏段默认只保留原声和原画面，字幕由用户自行决定；
- 导出时音频重新编码为 AAC，并用媒体探针检查音频轨存在且时长一致。

语义卡的 `trigger` 时间与示例见 [semantic-popup-timeline.csv](../examples/workbench-tutorial/timeline/semantic-popup-timeline.csv)。
