# Remotion 口播剪辑：分阶段提示词

在需要 Remotion 动态包装时，按顺序执行。参考截图只决定视觉表达；口播内容决定信息卡与动效表达。不得复制参考中的品牌元素。

## 1. 风格校准

```text
我提供了一组目标视频截图。它们仅用于分析视觉方向，不要照搬画面或复制对方品牌元素。

先不要剪辑，也不要编写 Remotion 代码。请：
1. 分析画幅、人物位置、构图与安全区；
2. 分析字幕、标题、信息卡与结论的层级；
3. 提取字体、颜色、面板、关键词强调和动效节奏；
4. 区分可复用规则与不应照搬的元素。

输出：风格拆解表、本片包装规则、禁止项、待我确认项。确认前停止。
```

## 2. 字幕、词级时间轴与逻辑分组

```text
这是原始口播视频、可选口播稿和已确认的风格规则。

先不要制作视频或编写 Remotion 代码。请：
1. 识别语音，并按实际口播校正错字、漏字、专有名词与中英文名称；
2. 输出校正后的毫秒级 SRT；
3. 输出可供动效触发的词级或字级 JSON；每项至少含 text、startMs、endMs、timestampMs、confidence；
4. 关键词必须使用真实词级时间，不能用整句起点代替；
5. 按完整论证单元分逻辑组，不按标点机械切分；每组写明传播作用、观众记忆点、组件与出入场方式；
6. 单独列出音频与文稿不一致及已修正的内容。

完成后停止，等我确认。
```

## 3. 关键帧门禁与审核预览

```text
请使用 Remotion，基于已确认的风格规则、词级时间轴和逻辑分组制作动态包装。

规则：输入先出现，关系随后出现，结果最后出现；同一逻辑组逐层累积，论点结束后整组退出；信息卡是语义总结，不照抄口播，单字段尽量不超过 15 个字；人物、眼睛、嘴部、手势和底部既有字幕均为保护区。

第一阶段：先生成开场、每个主逻辑段、信息量最大画面、可选录屏画中画和结尾的静态关键帧。逐帧检查文字越界、人物遮挡、逻辑顺序和安全区。关键帧未通过时停止，不渲染视频。

第二阶段：关键帧通过后，输出 1280×720、30fps、H.264 + AAC 的 15–20 秒带原声审核预览。用词级时间触发关键词；逐组检查字幕同步、元素累积、整组退出和 AAC 音轨。该版本只用于审核，不得当作最终成片。
```

## 4. 定点微调与最终渲染授权

```text
请基于当前已确认的预览进行定点修改。本轮只修改以下内容：

1. [时间点或范围]：[对象] 当前问题是 [问题]，请改为 [目标状态]。
2. [时间点或范围]：[对象] 当前问题是 [问题]，请改为 [目标状态]。

约束：只改以上内容，其他已确认部分保持不变。先输出受影响位置前后 2–3 秒的关键帧或短片段，并说明改动；若会连带影响已确认内容，先说明影响，不要自行扩大范围。

只有在我明确确认后，才从原始最高质量素材渲染最终成片，并核对字幕同步、画面安全区、分辨率、时长、帧率、编码和音频轨道。
```

## 5. 风格资产沉淀

```text
这条视频已确认完成。请以最终成片、确认的关键帧和实际修改记录为准，输出可跨视频复用的剪辑风格包：

1. style-guide.md：构图、安全区、字体、字幕、颜色、面板、语义组件、动效节奏、禁止项和失败案例；
2. style-prompt.txt：压缩为下一期可直接使用的提示词，写清输入、输出、确认节点、质量标准和禁止项；
3. reference-index.md：仅保留实际采用的参考图和关键帧，并写明用途；
4. lessons-learned.md：记录有效修改、失败版式和仍需人工确认的事项；
5. 下一期启动提示词：读取风格包与新素材后，按本流程执行。

不要写入本期专属标题、台词、时间点或绝对路径。旧规则与新内容冲突时，以新内容的表达逻辑为准，并说明原因。
```

## 验收清单

- 随机抽查 5–10 个关键词与原声是否同步。
- 静态关键帧通过后，才渲染审核预览。
- 每组遵循“输入 → 关系 → 结果”，结论后整组退出。
- 审核预览使用低分辨率；最终版必须从原始素材重新渲染。
- 正式成片交付前核对分辨率、时长、帧率、视频编码和 AAC 音轨。
